How we build

Native first

Rust, C++ and Swift underneath, and no bundled browser engine. Our apps start fast and stay light on memory and battery.

Every platform, for real

macOS, Windows and Linux get the same features and the same care, not a port that lags behind.

Your machine stays yours

Free to download, no accounts, no ads. Apps keep to their own folders and clean up after themselves.

Built and tested on all three

Every release is built and checked by automated pipelines on macOS, Windows and Linux before it reaches you.
